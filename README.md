# Typoha

Independent, local-first Markdown editor. Rust filesystem core and a bundled TypeScript editing surface. Original UI and assets; no proprietary editor code is used.

This project is under active implementation. Functional coverage and explicit limitations are tracked in [docs/parity.md](docs/parity.md). Do not assume complete compatibility or pixel identity with any other product.

See [AGENTS.md](AGENTS.md) for engineering rules and [docs/clean-room.md](docs/clean-room.md) for the source boundary.
