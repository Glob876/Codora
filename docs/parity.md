# Функциональное покрытие

Состояние версии 0.1.0. Это **работающая независимая реализация**, но **не полный клон 1:1**. Таблица фиксирует реальное покрытие, а не обещание совместимости со всеми документами или командами другого продукта.

Обозначения: **есть** — реализовано; **частично** — есть существенные различия; **внешнее** — необходим отдельный инструмент; **нет** — предстоит реализовать; **собственное** — намеренно собственное оформление/поведение.

## Ближайшие работы для достижения паритета

1. Расширить визуальную схему редактора: сноски, YAML, inline-маркеры, alerts, точное сохранение исходного синтаксиса.
2. Уточнить математику, нумерацию уравнений, совместимость экспортов.
3. Завершить файлы: системный выбор папки, drag-and-drop, недавние/закреплённые, перенос истории.
4. Добавить параметры экспортов, image uploaders, словари и клавиатурные настройки.
5. Подготовить нативную оболочку и проверить сборки на всех целевых ОС.

Для задач с точным форматом надёжнее использовать исходный режим. Визуальный редактор может нормализовать Markdown после реального редактирования; простое открытие/переключение режимов не должно переписывать файл.
