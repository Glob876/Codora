# Настройка консольной Codora

Консоль использует TOML-файл **`.typoha/config/console.toml` в открытой рабочей
папке**. Он создаётся при первом запуске. У каждого проекта свои настройки;
настольная версия продолжает использовать собственные настройки.

```bash
./run.sh console /путь/к/проекту
# После выхода откройте /путь/к/проекту/.typoha/config/console.toml
```

Полный образец находится в [console.example.toml](../console.example.toml).
Получить его без запуска интерфейса можно командой:

```bash
./run.sh console --print-config
```

После ручного редактирования перезапустите консоль. Для возврата к умолчаниям
удалите нужный параметр: все параметры необязательные. Неизвестный параметр,
неверный тип, некорректный цвет или значение вне диапазона вызывают явную ошибку
с именем файла. Codora не заменяет испорченный файл умолчаниями.

## Параметры

Все параметры этой таблицы располагаются **до** секций `[colors]` и `[bindings]`.
Числа записываются без кавычек, логические значения — `true` или `false`.

| Параметр | Умолчание | Что меняет / допустимые значения |
| --- | --- | --- |
| `theme` | `0` | `0` — тёмная Codora, `1` — светлая Codora, `2` — ANSI-цвета терминала |
| `numbers` | `true` | Номера строк |
| `hidden` | `false` | Скрытые файлы в дереве и поиске файлов |
| `indent` | `4` | Ширина табуляции, от 1 до 16 пробелов; меню перебирает 2/4/8 |
| `sidebar` | `true` | Показывать дерево файлов; на узком экране дерево скрывается автоматически |
| `focus` | `false` | Режим фокусировки: скрывает дерево |
| `sidebar_width` | `26` | Ширина дерева, 12–100 колонок; не больше половины экрана |
| `output_percent` | `32` | Доля высоты панели вывода Python, 10–70% |
| `preview_page_lines` | `15` | Шаг PgUp/PgDn в справке и Markdown-просмотре, 1–1000 строк |
| `autosave` | `false` | Автоматически сохранять изменённые именованные файлы |
| `autosave_delay_ms` | `2000` | Пауза после ввода перед автосохранением, 100–600000 мс |
| `draft_delay_ms` | `600` | Пауза перед записью черновика восстановления, 100–60000 мс |
| `poll_interval_ms` | `80` | Интервал ожидания событий, 10–1000 мс |

Интервалы срабатывают на ближайшем цикле обработки событий. Большой интервал
ожидания увеличивает задержку автосохранения и восстановления. Черновики работают
независимо от `autosave`. Конфликт с внешней версией файла отключает повторные
попытки автосохранения до его явного включения. Ограничения безопасности файлов,
история и проверки конфликтов остаются обязательными.

## Цвета

Тёмная тема использует цвета собственного логотипа Codora: персиковый `#FFC28A`,
малиновый `#C74359`, коралловый `#F36A52` и светлый текст `#FCF3E8`.
Светлая тема использует более тёмные акценты для читаемости. Тема `2` использует
ANSI-палитру терминала, включая логотип.

Переопределяйте любые цвета в секции `[colors]`; остальные берутся из выбранной
темы. Переопределения действуют при переключении темы через меню. Пример:

```toml
theme = 0
indent = 2

[colors]
accent = "#FFC28A"
selection_background = "#C74359"
selection_foreground = "#FCF3E8"
```

| Ключ | Элемент |
| --- | --- |
| `background` | Основной фон |
| `foreground` | Основной текст |
| `muted` | Номера строк, подсказки, строка состояния, границы |
| `accent` | Название приложения, вкладки, акценты интерфейса |
| `panel` | Фон панелей и текущей строки |
| `error` | Сообщения об ошибках |
| `selection_background` / `selection_foreground` | Выделение текста и выбранные пункты списков |
| `cursor` | Фон курсора редактора и полей ввода |
| `heading` | Заголовки и ссылки Markdown-просмотра |
| `code` | Блоки кода Markdown-просмотра |
| `logo_peach` | Символы `/` ASCII-логотипа |
| `logo_raspberry` | Символы `+` ASCII-логотипа |
| `logo_coral` | Символы `#` ASCII-логотипа |

Значения заключаются в кавычки: `"#RRGGBB"`, `"reset"` (цвет терминала),
либо имена `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `gray`,
`darkgray`, `lightred`, `lightgreen`, `lightyellow`, `lightblue`, `lightmagenta`,
`lightcyan`, `white`. Цвета RGB требуют поддержки true color в терминале.
Цвет логотипа в текстовом выводе `--help` не меняется: там используется обычный текст.

## Дополнительные горячие клавиши

```toml
[bindings]
"ctrl+j" = "save"
"f9" = "palette"
"alt+h" = "hidden"
"ctrl+shift+k" = "preview"
```

Допускаются F1–F12 с модификаторами или без них и один символ с Ctrl/Alt
(необязательный Shift). Регистр названий клавиш не важен. Дублирующиеся сочетания
запрещены. Терминал должен передавать выбранное сочетание приложению.

Эти привязки выполняются перед встроенными сочетаниями в основном интерфейсе:
можно переназначить существующую клавишу или добавить альтернативу. Остальные
встроенные сочетания продолжают действовать. Навигация, редактирование, управление
диалогами, подтверждение сохранения и клавиши закрытия просмотра остаются
встроенными; `[bindings]` их не переназначает внутри диалогов/просмотра.

Доступные команды:

- Документы: `new`, `open`, `save`, `save_as`, `close`, `quit`, `workspace`.
- Поиск: `find`, `replace`, `search`, `regex_search`, `outline`.
- Файлы: `history`, `drafts`, `trash`, `rename`, `mkdir`, `delete`, `duplicate`.
- Python: `run`, `stop`, `input`, `output`.
- Просмотр и конвертация: `preview`, `export`, `import`.
- Интерфейс: `palette`, `theme`, `numbers`, `autosave`, `indent`, `hidden`, `focus`, `help`.
- Markdown: `bold`, `italic`, `link`, `table`, `task`, `code`.

## Сохранение и перенос старых настроек

Изменения через Ctrl+E записываются в TOML атомарно. При этом файл форматируется
заново: комментарии удаляются, значения сохраняются. Если файл вручную изменён
во время работы, Codora показывает ошибку и отказывается его перезаписывать.
Перезапустите консоль, чтобы загрузить новую версию.

Если TOML ещё нет, параметры из старого ключа `console` в
`.typoha/config/preferences.json` автоматически переносятся. Исходный JSON не
изменяется; после переноса консоль читает TOML. Поэтому для полного сброса нужно
учесть и старый ключ `console`, если он существует. Для другой рабочей папки
загружается её собственный TOML.

Конфиг не включает графические функции настольной версии, произвольные shell-команды,
лимиты движка Python, настройки Pandoc, пользовательские шрифты или подсветку синтаксиса.
